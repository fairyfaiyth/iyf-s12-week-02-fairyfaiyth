# Week 2: CSS Mastery - Responsive Portfolio

Styled, mobile-first version of my Week 1 portfolio, built for IYF Season 12.

## Live Demo
https://fairyfaiyth.github.io/iyf-s12-week-02-fairyfaiyth/

## Pages
- `index.html`: home page with hero section
- `about.html`: about me
- `projects.html`: responsive project grid (1, 2 or 3 columns)
- `contact.html`: contact page with styled form
- `semantic-conversion.html`: Week 1 semantic HTML exercise

## Practice files
- `box-model-practice.html`: box model, debug exercise and card
- `flexbox-practice.html`: nav bar, card row and footer
- `grid-practice.html`: photo gallery, magazine layout and project grid
- `daily-challenges/`: buttons, card, hero, form and footer

## What I learned
- CSS reset, typography system and color scheme with CSS variables
- Box model and `box-sizing: border-box`
- Flexbox and Grid layouts
- Mobile-first responsive design with media queries
- Hover, transition and keyboard focus states
